## Learning Path

A practical progression for these **CTF labs**:

1. Start with **Shell Whisperer** to understand shell-oriented challenges.
2. Study **Tomcat configuration and credential security**.
3. Explore **Tomcat Manager** and WAR-related concepts.
4. Progress toward **Tomcat-to-root** challenges.
5. Practice the ZIP-focused labs.
6. Combine archive, credential, web, and privilege-escalation concepts into broader challenge-solving workflows.

## How to Use the Labs

Use these labs only in authorized environments such as CTF platforms, personal virtual machines, or intentionally vulnerable training systems.

For each challenge:

1. Read the lab objective.
2. Identify the relevant service or application.
3. Enumerate the available information within the authorized lab.
4. Analyze configuration, credentials, archives, or application behavior.
5. Document findings and security implications.
6. Apply the lesson to defensive security and penetration-testing knowledge.

Avoid testing techniques against systems without explicit authorization.
